# 羽球找團｜badminton-finder

個人用的小工具：找台北、新北、桃園、中壢的羽球臨打團，看「禮拜幾、哪個時段，有適合我程度（預設 10–12 級）的團」。

## 怎麼用

- **看**：直接打開 `index.html`（雙擊就好，不用架伺服器）
- **更新資料**：雙擊 `更新資料.command`，抓完會自動打開網頁
  - 或在終端機跑 `python3 scripts/fetch.py`
  - 只用 Python 標準函式庫，不用裝套件

## 自動更新

GitHub Actions 每天台灣時間 07:00 跑 `scripts/fetch.py`，資料有變才 commit 回 `main`。
要立刻更新：GitHub → Actions → 「每天更新羽球團資料」→ Run workflow。

## 畫面

- **星期 × 時段熱度表**：格子裡的大數字＝「很對口＋可以打」的團數；點一格就只列那個時段
- **當天強度組成**：每一天所有團裡，很對口／可以打／程度很雜／偏弱／偏強各佔多少
- **兩個分頁**：每週固定團（羽球拼圖）、近期場次（臨打情報站，有日期）
- 程度、地區、費用上限、團頁最後更新時間、收藏，都記在瀏覽器裡，下次打開還在

## 適合度怎麼算

以畫面上設定的程度 `[a, b]` 為準：

| 標籤 | 條件 |
|---|---|
| 很對口 | 團的範圍有涵蓋你，且團的下限 ≥ a − 2 |
| 可以打 | 有涵蓋你，但下限更低 |
| 程度很雜 | 範圍跨 12 級以上（如 1–18、6–18），或只寫「不限」 |
| 偏弱／偏強 | 團的上限 < a／團的下限 > b |

文字程度換算（羽球拼圖）：新手 1–3、初級 4–5、中下 6–7、中等 8–9、中上 10–12、高級 13–18。
「不限, 初級, 中下, 中等」這種寫法，會用後面列出的級別算出 4–9。

## 資料來源

| 來源 | API | 內容 |
|---|---|---|
| 羽球拼圖 badminton.pintu.tw | `GET /api/teams?city=台北市&pageSize=5000` | 每週固定團，有 `level_min`/`level_max` |
| 羽球臨打情報站 farreaching.com.tw/badminton | `GET https://badminton-api.farreaching.com.tw/api/v1/activities/lite` | 近兩週有日期的場次（多半來自 FB 社團） |

- 都是公開、不用登入的 API；一次更新只打 4 個請求，城市之間間隔 1 秒
- 中壢＝桃園市中壢區；「桃園」指桃園市中壢以外的區
- 某個來源抓失敗時，沿用上一次的那份資料，網頁上會顯示提醒
- 同一團重複登記（同名、同場館、同星期、同開始時間）只留最近更新的那筆

## 已知限制

- 團主自填，程度、費用、時間可能過期；去之前先私訊確認
- 桃園、中壢在這兩個平台上的團比較少，很多團只在 LINE 社群或 FB 社團（抓不到）
- `data/` 是抓下來的資料，`sessions.js` 給網頁用（`file://` 不能 fetch JSON），`sessions.json` 給腳本合併用

## 檔案

```
index.html          網頁（單一檔案，含 CSS/JS）
scripts/fetch.py    爬蟲
data/sessions.js    網頁讀的資料
data/sessions.json  同一份資料（JSON）
更新資料.command     雙擊更新
.github/workflows/update-data.yml  每天自動更新
```
